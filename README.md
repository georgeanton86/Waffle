# Waffle

A simple giveaway draw. Paste names, pick a style, and spin.

- **Show** is a game-show board.
- **Wheel** lands on a name.
- **Waffle** lights up square by square.

Spin length runs from 10 seconds to 90. More than one winner stays in the same spin. Names stay in the browser.

```bash
npm install
npm run dev
```

Open the app on port 8080.
